找到了根本原因：

根因：mpgresource.disposeOld() 在 setModel() 中被 post 两次
Config.songResourceGen 默认为 1。ResourcePool.disposeOld() 的规则是：每次调用 gen++，当 gen == maxgen 时释放资源。

在 GAProcessor.setModel() 中：

第 143 行：Gdx.app.postRunnable(() -> mpgresource.disposeOld()) — 第一次 post
第 255 行：disposeOld() 调用 GAProcessor.disposeOld()（第 265-267 行），里面又 post 了一次 mpgresource.disposeOld() — 第二次 post
GL 线程上执行顺序：

第一次 disposeOld：gen 0 → 1
第二次 disposeOld：gen 1 == maxgen(1) → 释放资源 → safeDispose() 设置 disposed = true
之后 play() 被调用 → if (disposed) return; → 静默退出
这就是为什么 "Triggering play()" 出现了但没有 "Video playback started"。

修复：删除第 255 行的 disposeOld() 调用（第 142-143 行已经处理了旧资源清理），让 mpgresource.disposeOld() 只 post 一次，gen 只从 0 变为 1，不会触发释放。
